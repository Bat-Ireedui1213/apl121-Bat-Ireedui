Томьёонууд:
-
-Нийт бууз = зочдын тоо * нэг хүнд ногдох бууз
-Гурил (кг) = нийт бууз *25/1000
-Мах (кг) = нийт бууз * 30/1000
-Хугацаа (мин) = нийт бууз * 20/100
